## About

**IL DENTE PROIBITO** is a personal profile link card built around a glassmorphic visual aesthetic. The site uses the [Lanyard API](https://github.com/Phineas/lanyard) to show live Discord presence, hosts a custom audio player, and consolidates the owner's social profiles and external links in a single place.

The project is deployed on Cloudflare Pages and was built with performance and low-latency rendering as primary design goals.

---

## Features

The following features are visible and active on the live website:

- **Click-to-enter gate** — A fullscreen entry overlay before the main card is revealed.
- **Real-time Discord presence** — Live Discord status fetched via the Lanyard API.
- **Custom audio player** — Inline audio playback embedded directly in the page.
- **Multilingual interface** — Content is available in English, Italian, and Russian.
- **Live visitor counter** — Real-time unique visitor count displayed on the page.
- **Background video** — A full-page video plays behind the card.
- **Ko-fi donation support** — A donation link is integrated via Ko-fi.
- **Social links** — Direct links to Ko-fi, X, TikTok, Telegram, and Email.
- **Discord friend link** — A direct link to add the owner as a Discord friend.
